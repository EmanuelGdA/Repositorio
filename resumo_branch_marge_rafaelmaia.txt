O que é uma Branch (Ramificação)
A Branch é um ambiente de trabalho isolado ou um "universo paralelo" que você cria a partir da linha principal do seu código (a main).

O que é Merge (Mesclagem)
O Merge é o ato de integrar todas as mudanças (commits) feitas em uma branch de desenvolvimento de volta à branch principal (main).

Uso em Trabalho em Equipe
Branch e Merge são vitais em um time, pois permitem que várias pessoas trabalhem juntas de forma segura e organizada:

Desenvolvimento Paralelo: Cada desenvolvedor cria sua própria branch (ex: feat/carrinho ou feat/checkout) para trabalhar em tarefas diferentes. O trabalho de ninguém interfere no trabalho do outro.

Revisão de Código (Pull Request): Em vez de fazer o Merge diretamente, você abre um Pull Request (PR). Isso é um pedido formal para que outro colega (ou líder técnico) revise e aprove seu código antes que ele toque na main, garantindo a qualidade.

Correção Rápida: Se um bug urgente aparecer no site (na main), a equipe cria uma branch específica para a correção (bugfix/erro-urgente), corrige, e faz o Merge rapidamente, mantendo o desenvolvimento das outras features em andamento.
